# My Portfolio

Personal portfolio website showcasing my software engineering experience and projects. Built with Astro for fast performance and modern web standards.

## About

My portfolio site featuring sections for introduction, professional experience, skills, and contact information.

## Project Structure

```
/
├── public/
│   └── favicon.svg
├── src/
│   ├── components/       # Reusable Astro components
│   ├── images/          # Image assets
│   ├── layouts/         # Page layouts
│   └── pages/           # Page routes
└── package.json
```

## Commands

| Command        | Action                                      |
| :------------- | :------------------------------------------ |
| `pnpm install` | Install dependencies                       |
| `pnpm dev`     | Start dev server at `localhost:3000`       |
| `pnpm build`   | Build production site to `./dist/`         |
| `pnpm preview` | Preview build locally before deploy        |

## Tech Stack

- **Astro** - Static site generator
- **pnpm** - Package manager
- **Sitemap** - SEO support

## Getting Started

```bash
pnpm install
pnpm dev
```

Visit `http://localhost:3000` to view the site locally.
